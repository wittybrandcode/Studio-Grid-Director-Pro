# Studio Grid Director Pro (SGD)
### نظام هندسة ومعايرة جدران وشاشات الـ LED للاستوديوهات والبث التلفزيوني والمسرحي
**Broadcast LED Wall Calibration, Pixel Mapping & Multi-Screen Stage Director**

---

## نظرة عامة | Overview

**Studio Grid Director Pro (SGD)** هو نظام هندسي متكامل لمعايرة شاشات وجدران الـ **LED Walls**، وتوليد خرائط البكسل (**Pixel Maps**)، وإدارة البث المباشر متعدد الشاشات في الاستوديوهات التلفزيونية والمسارح وغرف التحكم (**Control Rooms**).

تم تصميم النظام بهندسة بصرية مستوحاة من بيئات البث الاحترافية (**Resolume Arena / NovaStar LCT / Adobe After Effects**) بحواف حادة `0px`، ومحرك رسم **60FPS Zero-Lag** قادر على التعامل مع شاشات عملاقة تتجاوز **8K / 16K** بدون أي تأخير، مع نظام أرشفة مضغوط خاص بصيغة **`.sgd`** يدمج كافة الشاشات والصور المرجعية في حزمة ثنائية واحدة فائقة الخفة.

---

## المزايا الهندسية الرئيسية | Core Engineering Capabilities

### 1. إدارة المسرح متعدد الشاشات والبث المباشر اللحظي (Multi-Screen & Live Output Engine)
- **تعدد شاشات غير محدود**: إنشاء، نسخ، إعادة ترتيب، وتخصيص عدد غير محدود من الشاشات بأبعاد مستقلة (`FHD`, `4K UHD`, `8K`, `LED Ribbon`, `Vertical Totem`, أو أبعاد مخصصة حتى `16384×16384` بكسل).
- **نوافذ بث مباشر مستقلة (`Live Output Windows`)**: فتح نافذة عرض نقية بملء الشاشة لكل شاشة على حدة على مخارج بطاقة الشاشة (`HDMI / DP / SDI`) مع مزامنة لحظية بسرعة **40Hz (25ms)** عبر **Server-Sent Events (SSE)** و **BroadcastChannel**.
- **مسرح جميع الشاشات (`All Screens Panoramic Stage`)**: تجميع بصري تفاعلي لجميع الشاشات مع سحب وإفلات مغناطيسي (`0px Seamless Snap`)، وأوضاع ترتيب فورية (تلاصق أفقي `0px`، صف متباعد، تكديس عمودي، شبكة `2×2`)، و**الوضع النقي (`Pure Mode`)** لعرض الجدار كاملاً بدون أي قوائم أو أطراف تعديل.
- **نظام وميض التعريف الفوري (`Flash & Hold Identify`)**: إرسال ومضة كهرمانية/صفراء (`6Hz Strobe`) أو تثبيت بطاقة تعريف الشاشة (`Hold Pin`) على شاشة العرض المباشر لمعرفة موقع كل شاشة في الاستوديو فوراً.
- **تجميد البث المباشر (`Freeze Live Output`)**: إمكانية تجميد الصورة المعروضة على شاشات المسرح أثناء إجراء تعديلات وملاحظات محلية في غرفة التحكم ثم دفعها للبث بضغطة واحدة.

### 2. تقسيم الشبكة الذكي ونظام الترقيم والملاحظات (Precision Grid & Notes System)
- **طريقتا تقسيم هندسيتان**:
  1. **بالبكسل (`Pixels Mode`)**: تحديد حجم المربع بالبكسل (`Square px`) أو مستطيل مخصص (`Cw × Ch`) مع خيار محاذاة الباقي على الأطراف (`Start`) أو توزيعه بالتساوي في المنتصف (`Center`).
  2. **بالأعمدة والصفوف (`Columns × Rows`)**: تقسيم دقيق للشاشة إلى عدد محدد من الأعمدة والصفوف.
- **3 أنظمة ترقيم قياسية**:
  - **أحرف + أرقام (`A1, A2 ... B1`)**: النظام القياسي لتوجيه الكاميرات والفنيين.
  - **تسلسلي (`01, 02, 03...`)**: ترقيم متسلسل لجميع الصناديق.
  - **إحداثيات (`1-1, 1-2...`)**: ترقيم صف-عمود.
- **5 أنماط تلوين للشبكة**:
  - رقعة شطرنج داكنة (`Checkerboard`)، 16 لون بث متباين (`Broadcast 16`)، تدرج طيفي (`Rainbow`)، تلوين بالصفوف (`Rows`)، أو تلوين بالأعمدة (`Columns`).
- **نظام الملاحظات اللونية الذكي (`Color-Group & Single-Square Notes`)**:
  - ربط الملاحظات بلون تحديد كامل (ينطبق على جميع الصناديق المحددة بنفس اللون) أو بمربع مفرد بعينه.
  - **عزل بصري فوري (`Spotlight Isolation`)**: النقر على أي ملاحظة يعتم باقي الشاشة ويسلط الضوء على الصناديق المستهدفة مع لافتة إرشادية واضحة، مع إمكانية إرسال وميض تنبيهي (`Strobe Blink`) لتلك الصناديق على الشاشة الحية.

### 3. هندسة كابينات الـ LED والحسابات الكهربائية ومنافذ الشبكة (LED Cabinet, Power & Port Telemetry)
- **حسابات فيزيائية وكهربائية فورية**:
  - حساب المساحة بالمتر المربع (`m²`)، الأبعاد الفيزيائية بالمتر والسنتيمتر (`m / cm`)، والقطر بالبوصة (`inch`) بناءً على **Pixel Pitch (`mm`)** وأبعاد الكابينة بالبكسل (`Cab W × Cab H`).
  - حساب العدد الإجمالي للكابينات (`Cabinets`) والموديولات (`Modules`) وكشف الكسور الجزئية تلقائياً.
  - حساب استهلاك الطاقة الأقصى والمتوسط بالكيلوواط (`kW`) والأمبير (`Amps`) على جهد `220V` أو `110V`.
  - حساب عدد منافذ الإيثرنت (**1GbE Ethernet Ports**) المطلوبة وفق المعيار القياسي (`650,000 px / port @ 60Hz 8-bit`).
- **مخطط توصيل كابلات البيانات (`Snake Data Cabling Topology`)**:
  - رسم مسار كابلات الشبكة بين الكابينات على الشاشة بـ 4 اتجاهات قياسية (`Top-Left Horizontal`, `Top-Right Horizontal`, `Bottom-Left Horizontal`, `Top-Left Vertical`) مع تلوين كل منفذ (`P1, P2...`) بلون مستقل وترقيم تسلسل الكابينات.
- **مناطق معالجات الفيديو (`Processor Zones — NovaStar / Brompton`)**:
  - تقسيم الشاشة إلى مناطق معالجات أو منافذ إرسال مستقلة مع إطار لوني مخصص وتسمية لكل منطقة.
- **بطاقة المواصفات الهندسية وتصدير Pixel Map 1:1**:
  - توليد تقرير هندسي جاهز للطباعة (`Technical Patch & Spec Sheet`) وتصدير خريطة بكسل أصلية بدقة **1:1 Native PNG** لإدخالها في برامج **Resolume Arena** و **MadMapper** و **Disguise d3** و **NovaStar LCT**.

### 4. معايرة الألوان وأنماط الاختبار القياسية (Color Calibration & Broadcast Test Patterns)
- **6 أنماط اختبار هندسية قياسية**:
  - `Standard Grid` (شبكة المعايرة)، `SMPTE Bars` (أشرطة ألوان البث القياسية)، `Grayscale 16-Step` (تدرج الرمادي والتباين 16 خطوة)، `RGBW Ramp` (تدرجات القنوات اللونية)، `Checkerboard Contrast` (تباين الشطرنج ANSI)، و`Solid Field` (فحص البكسلات الميتة وتجانس اللوحة بـ 7 ألوان).
- **تحميل صور مرجعية مخصصة (`Custom Reference Image`)**:
  - رفع أي صورة اختبارية أو مخطط معماري مع تحكم كامل في نمط الاحتواء (`Fill`, `Contain`, `Cover`) ومستوى الشفافية (`Opacity`) لدمج الشبكة فوق الصورة.
- **معايرة إشارات اللوحة والـ RGB Gain**:
  - تحكم مباشر في السطوع (`Brightness`)، التباين (`Contrast`)، التشبع (`Saturation`)، حرارة اللون بالكلفن (`Color Temperature 3200K–9300K`)، الجامـا (`Gamma`)، وموازنة قنوات اللون (`Red / Green / Blue Gain`).
- **رادار القياس اللوني الحي (`Live Color Telemetry & Pixel Loupe`)**:
  - قراءة فورية لمستويات `RGB` و `HEX` و `IRE` تحت مؤشر الماوس بدون أي استهلاك لمعالج الرسوميات، مع نافذة تقرير معايرة الألوان الكامل (`Color Calibration Report`).

---

### 5. المساطر الذكية، مؤشر الليزر الحي، والرسم الحر (Rulers, Live Laser & Freehand Shapes)
- **نظام المساطر الهندسية وحساب المسافات (`Smart Rulers & Distance Matrix`)**:
  - سحب مساطر أفقية وعمودية مباشرة من حواف الشاشة مع انجذاب مغناطيسي (`Magnetic Snap`) لمنتصف الشاشة وحواف الصناديق.
  - زر **إحاطة التحديد بـ 4 مساطر (`Frame Selection`)** لقياس أبعاد أي كتلة محددة وعرض المسافات بالبكسل والنسبة المئوية تلقائياً.
- **مؤشر الليزر الحي التفاعلي (`Live Laser Pointer`)**:
  - توجيه شعاع ليزر حي يظهر في الوقت الفعلي على شاشات العرض المباشر بـ 3 أوضاع: شعاع حر (`Free Beam`)، خط قياس وتوجيه مستمر (`Line`)، أو تقاطع هندسي كامل (`Crosshair`) مع ذيل ضوئي متلاشٍ.
- **طبقة الرسم الحر والأشكال العضوية (`Freehand Pen & Organic Shapes`)**:
  - رسم مضلعات مغلقة (`Polygon`)، دوائر (`Ellipse`)، أسهم توجيهية (`Arrow`)، خطوط حرة (`Freehand`)، أو تحديد الصناديق بالحبل الحر (`Lasso Tiles`) لحساب مساحتها بالمتر المربع وعدد الكابينات فوراً.

---

### 6. صيغة الملفات المضغوطة الخاصة بالنظام (`.sgd` Binary Container Format)
- **بنية أرشيف `.sgd` الثنائية**:
  - بدلاً من ملفات النص التقليدية، يصدر النظام مشاريعه بصيغة **`.sgd`** (حاوية ثنائية مضغوطة بمستوى `DEFLATE Level 9`).
  - تحتوي الحزمة داخلياً على:
    - `manifest.json`: فهرس الحزمة، عدد الشاشات، وبصمات الأصول المدمجة.
    - `workspace.json`: الإعدادات الكاملة لجميع الشاشات، الملاحظات، المساطر، ومناطق المعالجات.
    - `assets/`: مجلد الصور المرجعية المرفوعة بصيغتها الثنائية الأصلية مع **إلغاء التكرار التلقائي (`FNV-1a Hash Deduplication`)** بحيث لا تتكرر الصورة إذا استُخدمت في أكثر من شاشة.
    - `preview.png`: لقطة معاينة مصغّرة للمشروع.
- **تنظيم ذكي عند فتح ملفات `.sgd`**:
  - عند استيراد أو سحب وإفلات ملف `.sgd` على مساحة العمل، يعرض النظام نافذة قرار سريعة بـ 4 خيارات:
    1. **حفظ الحالي وفتح الجديد (`Save Current & Open`)**
    2. **دمج الشاشات مع المشروع الحالي (`Merge Screens`)**
    3. **فتح دون حفظ السابق (`Open Without Saving`)**
    4. **إلغاء (`Cancel`)**

## اختصارات لوحة المفاتيح | Keyboard Shortcuts

| الاختصار | الوظيفة | Action |
| :--- | :--- | :--- |
| **`Space + Drag`** | تحريك الكاميرا بحرية على الشاشة | Pan Canvas Viewport |
| **`Mouse Wheel`** | تكبير وتصغير الشاشة باتجاه المؤشر | Zoom Toward Cursor |

| **`F`** | إرسال ومضة تعريف للشاشة الحالية | Flash Identify Active Screen |
| **`G`** | التبديل بين الشاشة المفردة ومسرح جميع الشاشات | Toggle Multi-Screen Wall Stage |
| **`P`** | تشغيل / إيقاف الوضع النقي بدون أي قوائم | Toggle Pure Distraction-Free Mode |
| **`M`** | إظهار / إخفاء رادار الشاشة المصغر (Minimap) | Toggle Minimap Radar |
| **`L`** | تشغيل / إيقاف مؤشر الليزر الحي | Toggle Live Laser Pointer |
| **`D`** | تشغيل / إيقاف أداة الرسم الحر والأشكال | Toggle Freehand Draw Tool |
| **`0`** | احتواء وتوسيط الشاشة في مساحة العرض | Fit Screen to Viewport |
| **`+` / `-`** | تكبير / تصغير تدريجي | Zoom In / Out |
| **`?`** | عرض نافذة اختصارات لوحة المفاتيح | Open Shortcuts HUD |
| **`Esc`** | إغلاق النوافذ المنبثقة أو الخروج من الوضع النقي | Close Modals / Exit Pure Mode |

## البنية التقنية والتشغيل | Technical Stack & Setup

### التقنيات المستخدمة
- **واجهة المستخدم ومحرك الرسم**: `React 19` + `TypeScript` + `HTML5 2D Offscreen Canvas Engine` + `Tailwind CSS 4`.
- **خادم المزامنة اللحظية**: `Node.js` + `Express` + `Server-Sent Events (SSE)` + `BroadcastChannel API`.
- **محرك الضغط والأرشفة (`.sgd`)**: `fflate` (Pure-JS High-Speed DEFLATE/ZIP Engine).

### خطوات التشغيل محلياً (Local Development & Production)

1. **تثبيت الحزم والاعتماديات**:
   ```bash
   npm install
   ```

2. **تشغيل بيئة التطوير (Development Server على المنفذ `3000`)**:
   ```bash
   npm run dev
   ```

3. **فحص الأنواع والـ Linting**:
   ```bash
   npm run lint
   ```

4. **بناء نسخة الإنتاج وتشغيل الخادم (Production Build & Start)**:
   ```bash
   npm run build
   npm start
   ```
